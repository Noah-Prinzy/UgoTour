UgoTour Phase 8.1 destination image sources

Destination photography is selected from exact-location Unsplash photo pages.
Pinterest remains a UI/motion inspiration source; low-resolution pins are not used as hero photography.
Run `npm run assets:download` to replace bundled compatibility placeholders with the selected high-resolution files.
Run `npm run assets:verify` afterward. The quality gate requires a completed 32/32 download manifest and at least 1400×800 pixels.
