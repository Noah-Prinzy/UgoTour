UgoTour Phase 8 image notes
============================

The website reads destination image paths from PostgreSQL, but the image files
live locally in this folder so the browser is not hotlinking production photos.

Bundled fallback files
----------------------
The ZIP contains locally bundled fallbacks derived from the two Pinterest-style
UI reference images supplied by the user in this conversation. They make the UI
work immediately even without internet access.

Source-image downloader
-----------------------
From the UgoTour root run:

    npm run assets:download

The downloader replaces the destination fallbacks with the selected web-source
photos below when internet access is available.
